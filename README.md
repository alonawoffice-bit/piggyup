# PiggyUp — גרסה סטטית עצמאית 🐷

בנייה מחדש של אפליקציית PiggyUp לחינוך פיננסי לילדים ולהורים — כקוד סטטי עצמאי,
ללא שרת. כל הנתונים נשמרים מקומית בדפדפן (`localStorage`).

## מבנה הפרויקט

```
piggyup-app/
├── index.html        # דף יחיד, עברית RTL, mobile-first
├── css/styles.css    # עיצוב: ירוק כהה + קרם, מצב כהה, רספונסיבי
├── js/data.js        # תוכן ולוגיקה טהורה: טיפים, משחקים, צ'טבוט, מנוי
├── js/app.js         # רינדור, ניתוב מסכים, פעולות, localStorage
└── README.md
```

אין שלב build — הקבצים נפרסים כמו שהם.

## הרצה מקומית

```bash
cd ~/workspace/piggyup-app
python3 -m http.server 8080
# ואז: http://localhost:8080
```

## פריסה ל-Cloudflare Pages

**אופציה א' — גרירה (הכי מהירה):**
1. להיכנס ל-dash.cloudflare.com → Pages → Create project → Upload assets
2. לגרור את תיקיית `piggyup-app` (או zip שלה)
3. מקבלים קישור חי מסוג `https://piggyup.pages.dev`

**אופציה ב' — דרך GitHub (מומלץ לעדכונים):**
1. ליצור ריפו חדש ב-GitHub ולהעלות את תיקיית `piggyup-app`
2. ב-Cloudflare Pages → Create project → Connect to Git
3. Build command: ריק · Build output directory: `/` (שורש הריפו)
4. כל `git push` מפרסם גרסה חדשה אוטומטית

## פיצ'רים

- מצב הורה / ילדים, פרופילי ילדים
- חלוקת כסף: חיסכון / השקעה / הוצאות
- יעדים עם אחוז התקדמות + הפקדות מהחיסכון
- משימות: יצירה → סימון "סיימתי" → אישור הורי → נקודות
- אווטר חזיר מתפתח ב-4 דרגות לפי נקודות (0 / 60 / 150 / 300) + מד התקדמות
- דשבורד הורה: יתרה, קטגוריות, ממתין לאישור, "מה קרה לאחרונה"
- מנוי: שבוע ניסיון חינמי → גרסה בסיסית חינמית; 19₪ ל-10 הראשונים / 29₪ אחר כך
- מרכז ליווי: טיפ יומי (מתחלף לפי תאריך), צ'טבוט מדריך מבוסס חוקים,
  4 רעיונות למשחקים המתחלפים כל שבוע (מתוך מאגר של 12)
- כלי הליווי נעולים אחרי הניסיון למנויים בלבד
- מצב כהה, עברית RTL מלאה, mobile-first

## החלטות תיעוד

- **אין סליקה אמיתית**: כפתור המנוי מפעיל מנוי מקומית להדגמה, עם כיתוב מפורש

- **הניסיון מתחיל בלחיצה** על "התחלת שבוע ניסיון חינם" (לא אוטומטי בכניסה ראשונה),

- **מחיר דינמי**: מונה מנויים מקומי; כל עוד פחות מ-10 נרשמו — 19₪, אחר כך 29₪.
- **שבוע המשחקים** מחושב לפי מספר שבוע ISO; הסט הבא נפתח ביום שני.
- **הצ'טבוט** מבוסס עץ החלטות + התאמת מילות מפתח לטקסט חופשי, בעברית בלשון נקבה.
- דרגות האווטר: חבר חדש (0) → חוסכת צעירה (60) → כוכבת החיסכון (150) → אלופת החיסכון (300).

## מה נבדק

- `node --check` לשני קבצי ה-JS — תקין
- בדיקות לוגיקה ב-Node על `js/data.js`: דרגות אווטר, טיפ יומי, סט משחקים שבועי,
  מספר שבוע ISO, סטטוס ניסיון/מנוי, מחיר למנוי הבא, התאמת מילות מפתח בצ'אט
- הגשה מקומית עם `python3 -m http.server` — הדף נטען (200 OK)

## מה נשאר לשלב הבא (backend אמיתי)

1. שרת + בסיס נתונים אמיתי (במקום localStorage) — כדי שהנתונים יישמרו בין מכשירים
2. סליקה אמיתית (Stripe / חברת סליקה ישראלית) במקום ההפעלה המקומית
3. התחברות משתמשים (הורה) במקום מצב מקומי יחיד
4. צ'טבוט מבוסס AI אמיתי במקום עץ החלטות
5. התראות / תזכורות (push או WhatsApp)
